# Simple KPI Tracking Sheet

## Project Overview
This project focuses on creating a simple KPI (Key Performance Indicator) tracking sheet using Google Sheets and the Sample Superstore Sales dataset. The dashboard summarizes important sales metrics in a single sheet.

## Objectives
- Analyze sales transaction data.
- Calculate key business performance indicators.
- Create a clear, easy-to-understand KPI summary.
- Use formulas to update results automatically when new data is added.

## Tools Used
- Google Sheets
- Sample Superstore Sales Dataset
- GitHub

## Key Performance Indicators (KPIs)
1. **Total Revenue:** Calculates the total sales revenue.
2. **Units Sold:** Calculates the total quantity of products sold.
3. **Average Order Value:** Calculates the average sales value per unique order.
4. **Top Product:** Identifies the product with the highest total sales revenue.

## Features
- Single-tab KPI summary.
- Formula-based calculations.
- Automatic recalculation when new data is added to the source data range.
- Consistent number and currency formatting.

## Dataset
The project uses the Sample Superstore Sales dataset, which contains order details, customer information, product categories, sales, quantities, discounts, and profits.

## Key Learnings
- Understanding business KPIs.
- Using Google Sheets formulas for data analysis.
- Summarizing raw transactional data into useful business insights.
- Presenting results in a clear and professional format.

## Conclusion
This project demonstrates how raw sales data can be transformed into a concise KPI summary to support business performance monitoring and decision-making.
